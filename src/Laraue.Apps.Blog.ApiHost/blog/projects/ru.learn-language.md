## Об изучении языков
Изучение нового языка - это долгий процесс, при котором мы пытаемся выучить огромное количество грамматики, правил, слов.

Но зачастую, не обязательно учить язык целиком для того чтобы начать им пользоваться. 80% повседневной речи составляют всего 300-500 слов.
Поэтому перед поездкой можно потратить месяц на изучение такого количества слов, чтобы чувствовать себя в новой стране намного комфортнее.

## Проблема маленького словарного запаса
Чтобы начать понимать язык, нужно выполнить три пункта:
1. Знать алфавит
2. Понимать базовую грамматику
3. Иметь достаточный словарный запас

Первые два пункта в большинстве популярных языков выполнимы за достаточно быстрое время. Но слова можно учить очень долго.
Трудно понять, какое их количество будет достаточным, и какие учить в первую очередь. Здесь хорошо срабатывает правило 80/20.
Лучшей идеей становится выучить 20% наиболее популярных слов, которые покроют 80% всех ваших нужд. Отлично, но как это сделать?
Пришлось разрабатывать приложение.

## Требования к приложению
- Приложение должно позволять увеличивать пассивный словарный запас с помощью системы квизов для запоминания слов в кратко и среднесрочной памяти,
- Генерировать предложения для последующего запоминания слов в долговременной памяти, а также использовать систему мотивации,
чтобы не давать бросать занятия.
- Приложение разработано, как Telegram бот, чтобы быть менее зависимым от платформы пользователя
- Слова и их переводы харнятся рядом с кодовой базой для возможности их изменения через Pull Requests с возможностью отслеживания истории.
- Слова для изучения взяты из публичных баз, мы старались собрать 5000 наиболее используемых слов.
- Переводы делаются с помощью AI, чтобы сократить время наполнения базы. Могут редактироваться в дальнейшем.
- Слова разделены на топики, чтобы дать возможность учить именно то, что нужно на текущем этапе.

## Архитектура предложения
- **[AutoTranslatorApp](https://github.com/win7user10/Laraue.Apps.LearnLanguage/tree/master/src/Laraue.Apps.LearnLanguage.AutoTranslator):** Коносльный сервис, который забирает слова из [translations.json](https://github.com/win7user10/Laraue.Apps.LearnLanguage/blob/master/src/Laraue.Apps.LearnLanguage.DataAccess/translations.json),
и выполняет их последовательный перевод на доступные [языки](https://github.com/win7user10/Laraue.Apps.LearnLanguage/blob/master/src/Laraue.Apps.LearnLanguage.DataAccess/languages.json).
- **[TelegramApiHost](https://github.com/win7user10/Laraue.Apps.LearnLanguage/tree/master/src/Laraue.Apps.LearnLanguage.Host):** обрабатывает запросы от бота с помощью [Telegram.NET](telegram-net).
Некоторые эндпоинты доступны для всех пользователей, некоторые только для админов.

## Функциональность
### Реализовано
- **Изучаемый язык:** В любом режиме, пользователь может выбирать язык для изучения из доступных пар.
Есть возможность задать это в настройках сразу для всех режимах.
- **Режим квиза:** Основной режим приложения. пользователю предлагается выбирать переводы для 20 вопросов.
Приложение старается соблюдать баланс между новыми словами, словами, что были выучены недавно, и словами, которые выучены давно.
- **Просмотр слов по топикам:** Возможность тренировать лексику только по специфичной теме. Например, путешествия.
- **Гибкие режими квиза:** Позволяет настраивать списки возможных слов для квиза. например по топику или уровню CEFR.

### Планы на будущее
- **Тексты для запоминания:** Генерация предложений с помощью ИИ из недавно выученных слов. Позволяет запомнить слова в контексте.
- **Вручную собранные топики для изучения:** Постараемся собирать лексику под конкретные жизненные ситуации. Поход в ресторан, театр, кофейню
или поездка в публичном транспорте.

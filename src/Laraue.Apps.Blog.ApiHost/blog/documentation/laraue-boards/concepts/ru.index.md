Прежде чем использовать Laraue Boards, стоит понимать, как части системы соотносятся друг с другом. Иерархия проста: задачи живут внутри эпиков, эпики — внутри пространств, а пространства принадлежат организации.

## В этом разделе

- [Задачи](/ru/blog/documentation/laraue-boards/concepts/issues) — Основная единица работы. Задача захвачена из сообщения Telegram или создана вручную, имеет уникальный ключ вида `WRK-42`.

- [Эпики](/ru/blog/documentation/laraue-boards/concepts/epics) — Канбан-доска с настраиваемыми колонками статусов. Задачи организованы внутри эпиков и перемещаются по колонкам по мере выполнения работы.

- [Пространства](/ru/blog/documentation/laraue-boards/concepts/spaces) — Группировочный уровень над эпиками. Используйте пространства для разделения работы с клиентами, продуктами или отделами.

- [Организации](/ru/blog/documentation/laraue-boards/concepts/organizations) — Общее рабочее пространство для команды. Участники организации могут видеть эпики и пространства и совместно работать в них.

## Как выглядит Иерархия в Laraue Boards

```
Организация
  └── Пространство (например «Мобильное приложение»)
        └── Эпик / Доска (например «Спринт 1»)
              └── Задача (например WRK-42)
```

Каждый уровень опционален. Пользователь может работать только с эпиками и задачами без создания пространств и организаций.

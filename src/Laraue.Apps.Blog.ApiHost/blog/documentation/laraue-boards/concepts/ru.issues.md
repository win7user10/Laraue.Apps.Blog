Issue — основная единица работы в Laraue Boards. Любая задача, запрос, баг-репорт или пункт действия — это issue. Отличие Laraue Boards в том, откуда берутся issues: большинство из них создаются из сообщений Telegram.

## Что входит в issue

У каждого issue есть:

- **Содержимое** — текст сообщения или текст, введённый вручную
- **Отправитель** — кто написал исходное сообщение в Telegram
- **Статус** — в какой колонке доски issue находится сейчас
- **Номер issue** — уникальный идентификатор вида `WRK-42`
- **Атрибуты** — любые кастомные поля, настроенные для доски
- **Медиа** — прикреплённые фото, видео или альбомы из исходного сообщения

![Экран деталей issue в Laraue Boards: содержимое, статус, номер issue, кастомный атрибут](https://laraue.com/static/images/blog/docs/laraue-boards/issue-details.jpg)

## Номера issues

Каждый issue получает номер на основе своего спейса, а не доски: три буквы из названия спейса и число, сквозное в пределах этого спейса, — например `WRK-1`, `WRK-2`, `MOB-14`. Перемещение issue между досками внутри одного спейса номер не меняет. Изменить его может только перенос в другой спейс.

Номер issue позволяет ссылаться на задачу в переписке. Напишите «см. WRK-42» в сообщении Telegram — и всей команде сразу понятно, о какой задаче речь, без необходимости делиться ссылкой.

У каждого issue есть и прямая ссылка, составленная из организации и номера:

```
https://boards.laraue.com/organizations/{OrgKey}/issues/{IssueKey}
```

Делитесь ссылкой, когда хотите привести человека сразу к issue, а не просто назвать его.

## Создание issues

**Из сообщения Telegram** — перешлите любое сообщение боту Laraue Boards. Оно сохранится и попадёт в бэклог дефолтного спейса. Бот подтвердит это реакцией 👍.

Сейчас все issues, созданные так, попадают в вашу **личную организацию**, независимо от того, из какого чата пришло сообщение. Привязка конкретных групповых чатов к конкретным организациям — например, чтобы сообщение из чата с клиентом сразу попадало в организацию этого клиента, — запланирована в одной из будущих версий.

**Вручную** — нажмите кнопку **+ Добавить задачу** в правом верхнем углу доски. Введите содержимое вручную.

## Перенос issue на другую доску

Новые issues от бота попадают на доску по умолчанию, чтобы сохранение оставалось лёгким, — не нужно выбирать доску перед отправкой сообщения. Если хотите разместить issue в другом месте, откройте **Бэклог**, найдите issue в списке и смените его доску прямо в деталях issue.

Перенос issue между досками **внутри одного спейса** сохраняет номер issue. Перенос в **другой спейс** даёт issue новый номер, поскольку номера считаются в пределах спейса.

## Перемещение issue между статусами

Перетащите карточку из одной колонки в другую. Номер issue не меняется — перемещение между колонками меняет только статус.

## Медиа в issues

Если исходное сообщение Telegram содержало фото, видео или альбом, они сохраняются в issue как одна карточка со всеми вложениями. Файлы не хранятся отдельно — они запрашиваются из Telegram при открытии, в исходном качестве. Карточка на доске показывает полосу до четырёх миниатюр. Нажатие на миниатюру открывает полноэкранный просмотр с навигацией между всеми вложениями.

## Редактирование issue

Если отредактировать исходное сообщение в Telegram, issue обновится вместе с ним. Реакция бота сменится на ❤, подтверждая, что правка обработана.

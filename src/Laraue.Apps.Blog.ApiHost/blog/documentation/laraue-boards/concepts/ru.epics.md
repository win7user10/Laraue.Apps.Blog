Эпик — это канбан-доска: именованный набор колонок статусов, группирующих связанные задачи. В Laraue Boards термины «доска» и «эпик» взаимозаменяемы. Каждый эпик имеет короткий префикс ключа (например `WRK` или `MOB`), который фигурирует в ключах задач.

## Создание эпика

Нажмите кнопку **+** в нижнем углу и выберите **Новая доска**. Заполните:

- **Название** — отображаемое имя, например «Спринт 1» или «Баги»
- **Ключ** — 2–4 символа в качестве префикса для ключей задач, автоматически генерируется из названия
- **Цвет** — используется для точки на вкладке навигации и карточках обзора досок

По умолчанию каждый новый эпик получает три колонки: **К выполнению**, **В работе** и **Готово**.

## Колонки статусов

Каждая колонка доски представляет статус. Задачи движутся слева направо по мере выполнения работы. Вы можете:

- **Добавить колонку** — нажмите **+ Добавить колонку** справа от доски
- **Изменить колонку** — нажмите иконку редактирования в заголовке колонки, чтобы переименовать её или изменить цвет
- **Удалить колонку** — задачи из удалённой колонки перемещаются в первую оставшуюся или в Бэклог, если колонок не осталось
- **Изменить порядок колонок** — перетащите колонку за заголовок

Количество колонок не ограничено. Простой рабочий процесс может иметь три колонки, более сложный — семь или восемь.

## Сортировка и фильтрация задач

В заголовке каждой доски есть элементы управления сортировкой и фильтрацией:

**Сортировка:**
- Вручную — порядок перетаскивания по умолчанию
- По времени — по временной метке сообщения, сначала новые
- По отправителю — в алфавитном порядке по имени отправителя

**Фильтр по атрибуту** — если вы добавили пользовательские атрибуты к доске, в строке фильтров появляются чипы. Нажмите на чип, чтобы показать только задачи с этим значением атрибута.

**Поиск по доске** — нажмите иконку поиска в заголовке доски. Введите текст — доска мгновенно покажет только подходящие карточки во всех колонках. Поиск сбрасывается при переходе на другую доску.

## Перетаскивание

Карточки можно перетаскивать между колонками, но не менять их порядок внутри колонки (порядок внутри колонки определяется настройкой сортировки). Изменение порядка колонок производится перетаскиванием заголовка колонки.

На сенсорных экранах удерживайте карточку перед перетаскиванием, чтобы отличить перетаскивание от прокрутки.

## Обзор досок

Когда Бэклог пуст (все задачи назначены), в представлении Бэклога отображается сводная сетка всех досок. Каждая карточка доски показывает:

- Сегментированный прогресс-бар, окрашенный по статусам — серый для «К выполнению», оранжевый для «В работе», зелёный для «Готово»
- Количество выполненных задач из общего числа
- Разбивку на активные, ожидающие и выполненные

Нажмите на любую карточку доски, чтобы перейти к ней.

## Удаление эпика

Откройте доску и нажмите меню **⋮**, затем выберите **Удалить доску**. Все задачи будут перемещены обратно в Бэклог. Отменить это действие нельзя.

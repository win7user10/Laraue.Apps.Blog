Эпик — это канбан-доска с именованным набором колонок статусов. В Laraue Boards термины «доска» и «эпик» используются как синонимы. Эпик работает только с внутренним id — у него нет собственного номера. Номера issue берутся из спейса, которому принадлежит эпик, а не из самого эпика.

![Эпик в Laraue Boards с issues, разложенными по колонкам статусов](https://laraue.com/static/images/blog/docs/laraue-boards/board-view.jpg)

## Создание эпика

Выберите спейс, в котором хотите добавить доску, нажмите **Создать доску** в правом верхнем углу. Заполните:

- **Название** — отображаемое имя, например «Спринт 1» или «Исправление багов»
- **Цвет** — используется для точки в навигационных вкладках

Новый эпик создается с одной колонкой — **Новое**. Остальные можно добавить и настроить позже, как описано ниже — или сразу скопировать весь набор статусов с одной из уже существующих досок, чтобы не собирать заново знакомый процесс колонка за колонкой.

**Копирование статусов с другого эпика** — на форме создания доски выберите эпик-источник, и его колонки статусов будут скопированы как есть, в том же порядке и с теми же цветами. После этого колонки всё равно можно редактировать, добавлять и удалять — копирование лишь задаёт стартовую точку.

![Выбор существующего эпика для копирования его колонок статусов при создании новой доски](https://laraue.com/static/images/blog/docs/laraue-boards/copy-epic-statuses.jpg)

## Колонки статусов

Каждая колонка на доске представляет статус. Issues двигаются слева направо по мере выполнения работы. Всё управление колонками — добавление, редактирование, удаление и изменение порядка — происходит в настройках доски, где статусы показаны списком строк:

- **Добавить колонку** — добавьте новую строку статуса
- **Отредактировать колонку** — переименуйте статус или измените его цвет
- **Удалить колонку** — issues в удалённой колонке удаляются вместе с ней навсегда. Мы планируем добавить шаг, на котором можно будет выбрать новый статус для этих issues перед удалением колонки, вместо того чтобы их терять.
- **Изменить порядок колонок** — перетащите строки статусов в нужном порядке

Ограничения на количество колонок нет. Простой процесс может обойтись тремя; более сложный — семью-восемью.

## Сортировка и фильтрация issues

В шапке каждой доски есть элементы управления сортировкой и фильтрацией:

**Сортировка** — сейчас карточки упорядочиваются вручную: перетащите карточку, чтобы изменить её порядок внутри колонки. Сортировка по другим критериям, например по времени или по отправителю, в разработке и появится в ближайшее время.

**Фильтр по атрибуту** — если для доски добавлены кастомные атрибуты, в панели фильтров появляются чипы. Нажмите на чип, чтобы показать только issues с этим значением атрибута.

![Фильтрация по кастомным атрибутам в панели фильтров доски](https://laraue.com/static/images/blog/docs/laraue-boards/filters-bar.jpg)

**Поиск по доске** — нажмите на иконку поиска в шапке доски. Введите любой текст, и доска мгновенно покажет только подходящие карточки во всех колонках. Поиск сбрасывается при переходе на другую страницу.

## Drag and drop

Карточки можно перетаскивать между колонками и менять их порядок внутри колонки перетаскиванием. Управление самими колонками — добавление, редактирование, удаление и изменение порядка — делается отдельно, в настройках доски.

На сенсорных экранах перед перетаскиванием нужно на мгновение зажать карточку, чтобы отличить перетаскивание от скролла.

## Перемещение issues между Бэклогом и доской

У каждого спейса свой Бэклог — доска по умолчанию, куда попадают новые issues от бота, если чат не [привязан](/ru/blog/documentation/laraue-boards/integrations/telegram-linking) к другому эпику. В Бэклоге откройте issue и назначьте ему любой другой эпик в том же спейсе. Вернуть issue обратно в Бэклог можно в любой момент из деталей issue.

## Бэклог

Бэклог любого спейса — это просто список issues, которые сейчас находятся на доске по умолчанию, точно так же, как любая другая доска показывает свои issues, только без колонок. Новые issues от бота попадают сюда первыми, если чат не [привязан](/ru/blog/documentation/laraue-boards/integrations/telegram-linking) к конкретному эпику. Когда в нём ничего нет, Бэклог просто пуст — отдельного сводного вида не существует.

![Бэклог со списком issues](https://laraue.com/static/images/blog/docs/laraue-boards/backlog-view.jpg)

## Удаление эпика

Откройте доску и нажмите на иконку настроек в правом верхнем углу. То же меню позволяет редактировать доску; чтобы удалить её, выберите **Удалить доску**. Все issues на доске удаляются вместе с ней навсегда. Это действие нельзя отменить.

Мы планируем добавить шаг, на котором можно будет выбрать новый эпик — или новый спейс — для issues перед удалением, вместо того чтобы их терять. Пока этого нет, переносите нужные issues самостоятельно перед удалением доски, если хотите их сохранить.

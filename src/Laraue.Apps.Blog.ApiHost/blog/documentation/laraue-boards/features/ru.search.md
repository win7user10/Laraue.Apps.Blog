В Laraue Boards есть поле поиска на каждой доске, в Бэклоге и на странице всех issues организации.

## Поиск на доске

Нажмите на иконку поиска в шапке доски. Поле раскрывается, и по мере ввода все колонки обновляются в реальном времени, показывая только подходящие карточки.

Нажмите Escape или на иконку ещё раз, чтобы закрыть. Поиск сбрасывается автоматически при переходе на другую доску.

## Поиск в Бэклоге

В шапке Бэклога такое же поле поиска, фильтрующее список issues в реальном времени по мере ввода.

## Поиск по всей организации

**All issues** в боковой панели — над списком ваших спейсов — показывает все issues организации вместе, независимо от того, на каком спейсе или доске они находятся. Каждая строка показывает спейс и доску, к которым относится issue, так что видно, где он на самом деле лежит.

![Страница All issues со списком issues из всех спейсов, полем поиска и кнопкой Filters](https://laraue.com/static/images/blog/docs/laraue-boards/all-issues.jpg)

На этой странице есть собственное поле поиска и кнопка **Filters** для дальнейшего сужения списка.

## Поиск и фильтры вместе

Поиск на доске и фильтры по атрибутам работают вместе — можно искать по тексту, одновременно фильтруя по атрибуту. Доска покажет только issues, подходящие и под поиск, и под активные фильтры.

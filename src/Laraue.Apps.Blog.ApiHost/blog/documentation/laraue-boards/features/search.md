Laraue Boards has a search box on every board and in the Backlog.

## Board search

Tap the search icon in the board header. The input expands, and as you type, all columns update in real time to show only matching cards.

Press Escape or tap the icon again to close. The search clears automatically when you navigate to a different board.

## Backlog search

The Backlog header has the same search control, filtering the issue list in real time as you type.

## Searching across the whole organization

**All issues** in the sidebar — above your list of spaces — shows every issue in the organization together, regardless of which space or board it's on. Each row shows the space and board it belongs to, so you can tell where an issue actually lives.

![The All issues page, listing issues from every space with a search box and Filters](https://laraue.com/static/images/blog/docs/laraue-boards/all-issues.jpg)

It has its own search box and a **Filters** button for narrowing the list further.

## Search and filters together

Board search and attribute filters work together — you can search for text while also filtering by an attribute. The board shows only issues that match both.

Атрибуты — это пользовательские поля, прикреплённые к каждой задаче на доске. Они позволяют добавлять структурированные метаданные — приоритет, команду, имя клиента, спринт или что угодно, что нужно вашему рабочему процессу — и фильтровать доску по этим значениям.

Атрибуты создаются на уровне **организации**, поэтому одна и та же библиотека атрибутов доступна на всех досках организации.

## Типы атрибутов

| Тип                 | Для чего                                                                                               | Статус         |
|---------------------|--------------------------------------------------------------------------------------------------------|----------------|
| **Список (Select)** | Фиксированный набор вариантов — Приоритет (Низкий/Средний/Высокий/Критический), Команда, Метка статуса | Доступно       |
| **Текст**           | Произвольный текст — заметки, URL, справочные номера                                                   | Доступно       |
| **Дата**            | Дата календаря — дедлайн, дата проверки, целевой релиз                                                 | Скоро          |

> **Примечание:** Атрибуты типа «Дата» пока не реализованы. Списки и текстовые атрибуты полностью поддерживаются.

## Кто может управлять атрибутами

Вкладка **Управление атрибутами** отображается в навигации доски для пользователей с разрешением **Управление атрибутами**. По умолчанию это разрешение выдаётся администратору организации. Остальные участники могут видеть и использовать атрибуты, но не могут создавать, редактировать или удалять их.

## Добавление атрибутов

Атрибуты создаются на уровне организации и затем доступны на каждой доске. Откройте любую доску и нажмите **Управление атрибутами** в навигационных вкладках. На открывшейся странице нажмите **+ Добавить атрибут**, выберите тип (Список или Текст), дайте ему название и — для Списка — добавьте доступные варианты.

Каждый атрибут имеет цвет, используемый для чипов фильтра и тегов атрибутов на карточках.

## Установка значений атрибутов

Откройте детали задачи и нажмите иконку редактирования. Поля атрибутов появятся под текстовым содержанием. Для атрибутов типа Список — выпадающий список с вариантами. Для Текста — поле произвольного ввода.

Значения отображаются как цветные теги в нижней части карточки на доске.

## Фильтрация по атрибуту

Когда доска имеет атрибуты типа Список, чипы фильтра появляются в строке фильтров под вкладками навигации. Нажмите на чип, чтобы отобразить только задачи с этим значением. Несколько фильтров комбинируются — показываются только задачи, соответствующие всем выбранным значениям.

Нажмите **✕ Очистить**, чтобы снять все активные фильтры.

## Фильтрация в поиске

Глобальный поиск также учитывает значения атрибутов. При поиске по доскам можно комбинировать текстовый поиск с фильтрами по атрибутам.

## Популярные варианты настройки атрибутов

**Приоритет:** Список — Низкий, Средний, Высокий, Критический (красный цвет)

**Команда:** Список — Фронтенд, Бэкенд, Дизайн, QA

**Спринт:** Список — Спринт 1, Спринт 2, Спринт 3

**Среда:** Список — Dev, Staging, Production

**Заметки:** Текст — произвольный контекст или ссылки

## Атрибуты vs статусы

Статусы (колонки) представляют, где в рабочем процессе находится задача. Атрибуты представляют дополнительные факты о задаче, которые не меняют её положение в рабочем процессе. Задача может быть «В работе» (статус) и «Высокий приоритет, Команда Бэкенд» (атрибуты) одновременно.

## Удаление атрибута

На странице управления атрибутами нажмите иконку удаления рядом с атрибутом. Атрибут и все его значения будут удалены из всех задач на доске. Отменить это действие нельзя.

Атрибуты — это пользовательские поля, прикреплённые к каждой задаче на доске. Они позволяют добавлять структурированные метаданные — приоритет, команду, срок сдачи, имя клиента или что угодно, что нужно вашему рабочему процессу — и фильтровать доску по этим значениям.

## Типы атрибутов

| Тип                 | Для чего                                                                                               |
|---------------------|--------------------------------------------------------------------------------------------------------|
| **Список (Select)** | Фиксированный набор вариантов — Приоритет (Низкий/Средний/Высокий/Критический), Команда, Метка статуса |
| **Текст**           | Произвольный текст — заметки, URL, справочные номера                                                   |
| **Дата**            | Дата календаря — дедлайн, дата проверки, целевой релиз                                                 |

## Добавление атрибутов на доску

Откройте доску и нажмите **Атрибуты** в FAB-меню (внизу справа). Нажмите **+ Добавить атрибут**, выберите тип, дайте ему название и (для Списка) добавьте варианты.

Каждый атрибут имеет цвет, используемый для чипов фильтра и тегов атрибутов на карточках.

## Установка значений атрибутов

Откройте детали задачи и нажмите иконку редактирования. Поля атрибутов появятся под текстовым содержанием. Для атрибутов типа Список — выпадающий список с вариантами. Для Текста — произвольный ввод. Для Даты — выбор даты.

Значения отображаются как цветные теги в нижней части карточки на доске.

## Фильтрация по атрибуту

Когда доска имеет атрибуты типа Список, чипы фильтра появляются в строке фильтров под вкладками навигации. Нажмите на чип, чтобы отобразить только задачи с этим значением. Несколько фильтров комбинируются — показываются только задачи, соответствующие всем выбранным значениям.

Нажмите **✕ Очистить**, чтобы снять все активные фильтры.

## Фильтрация в поиске

Глобальный поиск также учитывает значения атрибутов. При поиске по доскам можно комбинировать текстовый поиск с фильтрами по атрибутам.

## Популярные варианты настройки атрибутов

**Приоритет:** Список — Низкий, Средний, Высокий, Критический (красный цвет)

**Команда:** Список — Фронтенд, Бэкенд, Дизайн, QA

**Дедлайн:** Дата

**Спринт:** Список — Спринт 1, Спринт 2, Спринт 3

**Среда:** Список — Dev, Staging, Production

## Атрибуты vs статусы

Статусы (колонки) представляют, где в рабочем процессе находится задача. Атрибуты представляют дополнительные факты о задаче, которые не меняют её положение в рабочем процессе. Задача может быть «В работе» (статус) и «Высокий приоритет, Команда Бэкенд, Дедлайн 15 января» (атрибуты) одновременно.

## Удаление атрибута

В модальном окне управления атрибутами нажмите иконку удаления рядом с атрибутом. Атрибут и все его значения будут удалены из всех задач на доске. Отменить это действие нельзя.

Атрибуты — это кастомные поля, которые можно прикрепить к issues: приоритет, тип или что угодно ещё, что нужно вашему процессу. Они задаются на **уровне организации**, поэтому одни и те же атрибуты доступны на всех досках организации.

![Страница настроек Attributes со списком существующих атрибутов и их типами](https://laraue.com/static/images/blog/docs/laraue-boards/attributes-list.jpg)

## Типы атрибутов

| Тип                | Для чего                                                                                       |
|---------------------|-------------------------------------------------------------------------------------------------|
| **Text**            | Свободный текст — заметки, ссылки, номера для справки                                          |
| **List**            | Фиксированный набор вариантов — уровни приоритета, тип issue, что угодно из выпадающего списка |
| **Integer**         | Целое число — story points, количество                                                         |
| **Decimal**         | Число с десятичными знаками — цена, оценка в часах                                             |
| **Date**            | Календарная дата — дедлайн, срок                                                                |
| **Date and time**   | Календарная дата со временем — конкретный момент, а не просто день                             |

## Управление атрибутами

Откройте **Settings → Attributes** в боковой панели. Нажмите **+ New attribute**, задайте имя, выберите цвет и тип.

![Форма создания атрибута с полями Name, Color и Type](https://laraue.com/static/images/blog/docs/laraue-boards/create-attribute.jpg)

Для атрибута типа List добавьте его варианты — нажимайте **+ Add option** для каждого и удаляйте любой значком корзины рядом с ним.

![Страница редактирования атрибута типа List с его вариантами](https://laraue.com/static/images/blog/docs/laraue-boards/edit-attribute.jpg)

## Кто может управлять атрибутами

Управление атрибутами — создание, редактирование или удаление — требует административного права **Manage attributes**. По умолчанию оно никому не выдаётся — участнику нужно получить его явно, как и любое другое право. Участники без этого права всё равно видят атрибуты и могут пользоваться ими в issues.

## Фильтрация по атрибуту

Когда на доске используются атрибуты типа List, в панели фильтров появляются чипы. Нажмите на чип, чтобы отфильтровать только issues с этим значением. Несколько фильтров комбинируются — показываются только issues, подходящие под все выбранные значения.

## Атрибуты и статусы

Статусы (колонки) показывают, на каком этапе рабочего процесса находится issue. Атрибуты — это дополнительные факты об issue, не меняющие его позицию в процессе. Issue может быть одновременно «В работе» (статус) и «Высокий приоритет» (атрибут).

## Удаление атрибута

На странице редактирования нажмите **Delete attribute**. Поскольку атрибуты задаются на уровне организации, это удалит его — и все его значения — из каждого issue во всей организации, а не только на одной доске. Это действие нельзя отменить.

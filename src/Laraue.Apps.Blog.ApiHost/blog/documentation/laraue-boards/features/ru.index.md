Этот раздел является справочником по функциям — подробные руководства по каждой возможности Laraue Boards.

## В этом разделе

- [Пользовательские атрибуты](/ru/blog/documentation/laraue-boards/features/attributes) — Добавляйте пользовательские поля (приоритет, команда, дедлайн и что угодно ещё) к задачам и фильтруйте доску по ним.

- [Поиск](/ru/blog/documentation/laraue-boards/features/search) — Находите задачи по тексту, отправителю или чату. Поиск по доске, Бэклогу, глобальный поиск и поиск по навигации.

- [Медиавложения](/ru/blog/documentation/laraue-boards/features/media) — Как фотографии и видео из сообщений Telegram хранятся, отображаются на карточках и воспроизводятся в полноэкранном просмотрщике.

- [Ключи задач](/ru/blog/documentation/laraue-boards/features/card-keys) — Каждая задача получает уникальный ключ вида `WRK-42`. Как генерируются ключи, где они отображаются и как ссылаться на них в Telegram.

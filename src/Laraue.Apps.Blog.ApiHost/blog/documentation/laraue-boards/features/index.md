This section is the feature reference — detailed guides for each capability of Laraue Boards.

## In this section

- [Custom attributes](/blog/documentation/laraue-boards/features/attributes) — Add custom fields (priority, team, due date, and anything else) to issues and filter the board by them.

- [Search](/blog/documentation/laraue-boards/features/search) — Find issues by text, sender, or source chat. Covers board search, Backlog search, global search, and navigation search.

- [Media attachments](/blog/documentation/laraue-boards/features/media) — How photos and videos from Telegram messages are stored, displayed in cards, and played in the full-screen viewer.

- [Issue keys](/blog/documentation/laraue-boards/features/card-keys) — Every issue gets a unique key like `WRK-42`. How keys are generated, where they appear, and how to reference them in Telegram.

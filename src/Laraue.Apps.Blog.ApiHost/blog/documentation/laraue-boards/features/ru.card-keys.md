Каждый issue получает уникальный номер — короткий идентификатор вроде `WRK-42` или `MOB-7`. Номера позволяют ссылаться на конкретный issue в переписке или делиться прямой ссылкой на него.

## Как генерируется номер

Номер состоит из двух частей: трёх букв из названия **спейса** и числа, сквозного в пределах этого спейса. `WRK-1`, `WRK-2`, `MOB-14` — нумерация принадлежит спейсу, а не отдельной доске внутри него.

У эпика (доски) нет собственного номера — он работает только с внутренним id.

## Когда номер меняется

Перенос issue на другую доску **внутри того же спейса** номер не меняет. Перенос в **другой спейс** даёт issue новый номер, поскольку нумерация ведётся по спейсу, — любая ссылка или упомянутый номер, которыми уже поделились по этому issue, будут указывать на старый номер и перестанут работать.

## Использование номеров в Telegram

Напишите номер в любом сообщении Telegram — «см. WRK-42» — и всем, у кого есть доступ, сразу понятно, о каком issue речь.

## Прямая ссылка на issue

У каждого issue есть и прямая ссылка:

```
https://boards.laraue.com/organizations/{OrgKey}/issues/{IssueKey}
```

Рядом с номером на самом issue есть иконка ссылки — нажмите её, чтобы скопировать ссылку, не набирая её вручную.

![Иконка ссылки рядом с номером issue, используется для копирования прямой ссылки](https://laraue.com/static/images/blog/docs/laraue-boards/copy-issue-link.jpg)

## Где отображается номер

- В строке issue в Бэклоге и в списках
- В деталях issue, рядом с заголовком, вместе с иконкой копирования ссылки

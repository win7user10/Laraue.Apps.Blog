Каждая задача, назначенная на доску, получает уникальный ключ — короткий буквенно-цифровой идентификатор вида `WRK-42`, `MOB-7` или `BUG-103`. Ключи позволяют ссылаться на конкретные задачи в разговоре без необходимости делиться ссылкой.

## Как генерируются ключи

Ключ состоит из двух частей: префикса доски и порядкового номера.

**Префикс доски** формируется из названия доски — по умолчанию первые три заглавные буквы названия без небуквенных символов. «Work» становится `WRK`, «Sprint 1» — `SPR`, «Bug Fixes» — `BUG`. Можно задать пользовательский префикс при создании или редактировании доски.

**Порядковый номер** начинается с 1 и увеличивается с каждой задачей, назначенной на эту доску. Номера никогда не переиспользуются — если задача `WRK-5` удалена, следующая задача получит `WRK-6`, а не `WRK-5`.

## Когда присваивается ключ

Задача получает ключ в момент назначения на доску. Задачи в Бэклоге, не назначенные ни на одну доску, используют временный ключ `MSG-N`.

При перемещении задачи с одной доски на другую она получает новый ключ доски назначения. Перемещение между колонками в рамках одной доски ключ не меняет.

## Использование ключей в Telegram

Напишите ключ в любом сообщении Telegram — «см. WRK-42» или «исправлено в MOB-15» — и все участники команды с доступом к доске сразу поймут, о какой задаче речь. Делиться URL не нужно.

Ключи доступны для поиска в Laraue Boards. Введите `WRK-42` в любом поле поиска, чтобы найти именно эту задачу.

## Где отображаются ключи

- **На карточке доски** — мелким моноширинным текстом рядом с именем отправителя
- **В деталях задачи** — в виде заметного значка-таблетки в заголовке
- **В результатах поиска** — рядом с содержимым задачи

## Ключи и Jira

Если ваша команда мигрирует из Jira, формат ключей будет знакомым. Основные отличия:

- Ключи в Laraue Boards привязаны к доске, а не к проекту
- Ручная установка номера ключа недоступна
- Ключи не являются прямыми ссылками — используйте поиск для перехода к задаче

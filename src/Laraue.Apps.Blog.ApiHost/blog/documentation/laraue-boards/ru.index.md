Ваша команда уже работает в Telegram. Там принимаются решения, ставятся задачи, передаются файлы. Laraue Boards встраивается прямо в этот процесс — превращая сообщения, которые вы уже отправляете, в структурированные задачи на канбан-доске. Без необходимости менять способ общения.

![Канбан-доска в Laraue Boards с задачами, распределенными по статусам](https://laraue.com/static/images/blog/docs/laraue-boards/board-example.jpg)

## Что такое Laraue Boards

Laraue Boards — это инструмент управления проектами, построенный вокруг одного наблюдения: **задача уже существует в момент, когда кто-то отправляет сообщение**. Вам нужен только способ её организовать.

- Откройте как **Telegram Mini App** — без отдельного входа и нового аккаунта
- Или используйте полноценное **веб-приложение** на [msgboard.laraue.com](https://msgboard.laraue.com)
- Отправьте сообщение боту — текст, фото, видео или альбом — и оно станет задачей автоматически, без лишних действий
- Отредактируйте сообщение в Telegram — задача обновится вместе с ним
- Организуйте задачи в **Эпики** (доски) с настраиваемыми колонками статусов
- Группируйте эпики в **Пространства** для разных проектов или клиентов
- Настраивайте **кастомные атрибуты** для задач — свои поля под ваш процесс
- Работайте с командой через **Организации** с правами доступа, настраиваемыми по каждой операции

![Насйтрока прав доступа в Laraue Boards](https://laraue.com/static/images/blog/docs/laraue-boards/permissions-setup-example.jpg)

## Основные понятия

| Понятие                  | Что это                                                                                                                                    |
|--------------------------|--------------------------------------------------------------------------------------------------------------------------------------------|
| **Задача (Issue)**       | Единица работы, сохраненная из сообщения Telegram или созданная вручную. Имеет уникальный номер в пределах пространства, например `WRK-42` |
| **Эпик (Epic)**          | Доска с колонками статусов — ваш канбан                                                                                                    |
| **Пространство (Space)** | Группа связанных эпиков, например проект или клиент                                                                                        |
| **Организация**          | Общее рабочее пространство для вашей команды, с правами доступа для каждого участника                                                      |
| **Бэклог (Backlog)**     | Эпик по умолчанию, куда попадают задачи, пока вы не разложили их по своим доскам                                                           |
| **Кастомный атрибут**    | Собственное поле для задач — например, тип или приоритет, — которое настраивает администратор                                              |

## Для кого

**Один пользователь** — используйте как личный органайзер задач. Сообщения Telegram становятся бэклогом, доски — вашим рабочим процессом. Команда не нужна.

**Небольшие команды** — создайте организацию, пригласите коллег по ссылке, делитесь досками. Особенно удобно для команд в СНГ, где Telegram является основным инструментом деловой коммуникации.

**Агентства** — разделите работу с клиентами по пространствам, отслеживайте что обсуждалось и что сделано, без покупки отдельного PM-инструмента для каждого клиента.

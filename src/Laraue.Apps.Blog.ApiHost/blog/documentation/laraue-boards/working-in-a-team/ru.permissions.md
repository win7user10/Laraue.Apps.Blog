Laraue Boards использует иерархическую модель прав доступа. Права могут быть предоставлены на трёх уровнях: для всей организации, конкретного пространства или конкретного эпика (доски). Грант на более высоком уровне автоматически распространяется на все уровни ниже.

## Типы прав доступа

| Право          | Что разрешает                                               |
|----------------|-------------------------------------------------------------|
| **Чтение**     | Просматривать задачи, доски и пространства                  |
| **Создание**   | Создавать новые задачи и доски                              |
| **Обновление** | Редактировать существующие задачи и настройки досок         |
| **Удаление**   | Удалять задачи и доски                                      |
| **Управление** | Всё вышеперечисленное плюс управление участниками и правами |

## Как работает иерархия

Если пользователь имеет право **Чтение** на уровне Организации, он может читать всё внутри этой организации — все пространства и все доски — без необходимости предоставлять право на каждом уровне по отдельности.

Если право **Чтение** предоставлено только на уровне Пространства «Мобильное приложение», пользователь видит все доски в этом пространстве, но не видит доски в других пространствах.

Если право **Чтение** предоставлено только на уровне Эпика «Спринт 1», пользователь видит только эту доску.

**Права высшего уровня переопределяют права низших уровней.** Если право на уровне организации предоставлено, флажки для пространств и эпиков автоматически отмечаются и блокируются — они унаследованы и не могут быть сняты по отдельности.

## Настройка прав для участника

Откройте **Моя организация** в меню аватара пользователя. На вкладке **Участники** нажмите иконку прав (значок гистограммы) рядом с именем участника.

Вкладка прав показывает таблицу:

- Строки: Организация → Пространства (все) → Конкретные пространства → Эпики в пространстве → Конкретные эпики
- Столбцы: Управление, Создание, Чтение, Обновление, Удаление
- Заблокированные флажки означают унаследованные права от родительского уровня

Нажмите **▶ Эпики** рядом с любым пространством, чтобы раскрыть уровень эпиков. Первая строка «⚡ Все эпики в этом пространстве» позволяет задать права для всех эпиков пространства одним действием. Ниже — отдельные эпики для точной настройки.

Установите или снимите флажки и нажмите **Сохранить**.

## Практические примеры

**Подрядчик, которому видно только одно пространство:**
- Нет прав на уровне организации
- Право Чтение только для конкретного пространства

**Разработчик, который может работать с задачами, но не удалять:**
- Чтение на уровне организации
- Создание и Обновление на уровне организации
- Удаление не предоставлено ни на одном уровне

**Полноправный участник команды:**
- Чтение, Создание, Обновление на уровне организации
- Управление для пространств, которыми они владеют

**Администратор:**
- Управление на уровне организации (распространяется на всё)

## Права по умолчанию для новых участников

Новые участники, присоединившиеся по пригласительной ссылке, получают право **Чтение** на уровне организации по умолчанию. Они могут видеть все доски, но не могут создавать, редактировать или удалять что-либо до явного предоставления этих прав.

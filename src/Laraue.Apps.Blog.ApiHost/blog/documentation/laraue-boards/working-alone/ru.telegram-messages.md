Идея, лежащая в основе Laraue Boards, в том, что работа уже происходит в Telegram. Запрос клиента, баг-репорт, фото того, что нужно починить, — всё это issues, просто ещё не структурированные. Laraue Boards сохраняет их напрямую.

## Пересылка сообщения боту

Самый простой способ сохранить сообщение:

1. Зажмите любое сообщение в любом чате Telegram
2. Нажмите **Forward**
3. Выберите **@msgboard_bot** получателем
4. Сообщение сразу становится issue на вашей доске по умолчанию

![Пересланное сообщение в Telegram с реакцией бота, подтверждающей сохранение](https://laraue.com/static/images/blog/docs/laraue-boards/message-board-bot-processed-message.jpg)

Это работает для текстовых сообщений, фото, видео и альбомов.

## Что сохраняется

При пересылке сообщения Laraue Boards сохраняет:

- **Текстовое содержимое** сообщения (до 4096 символов)
- **Фото** и **видео** — показываются миниатюрами на карточке issue, запрашиваются из Telegram в исходном качестве при открытии
- **Имя отправителя** — показывается на карточке для контекста
- **Метку времени** — когда было отправлено исходное сообщение

Что не сохраняется: реакции, ответы, цепочки атрибуции пересланных сообщений и расшифровки голосовых сообщений.

## Вложения у issue

На карточке доски миниатюр нет — медиа появляется только при открытии issue. На странице деталей есть раздел **Attachments** под содержимым, показывающий каждое фото и видео маленькой миниатюрой. Нажмите на неё, чтобы открыть полное изображение.

![Раздел Attachments на странице деталей issue](https://laraue.com/static/images/blog/docs/laraue-boards/issue-attachments.jpg)

Отсюда же можно добавить свои изображения — **Choose other images** или вставить картинку напрямую через **Ctrl+V** — и удалить любое вложение крестиком на его миниатюре.

## Issues без текста

Сообщению не обязательно иметь текст, чтобы стать issue. Фото без подписи становится issue только с медиа — карточка показывает полосу миниатюр без текста под заголовком.

## Issues, созданные вручную

Issues, созданные через **+ Add issue**, не связаны ни с каким сообщением Telegram. У них те же поля (содержимое, статус, атрибуты), но нет отправителя или медиа из Telegram.

Основная идея Laraue Boards: работа уже происходит в Telegram. Запрос клиента, сообщение о баге, фото чего-то, что нужно исправить — это всё задачи, просто ещё не структурированные. Laraue Boards захватывает их напрямую.

## Пересылка сообщения боту

Самый простой способ захватить сообщение:

1. Удерживайте любое сообщение в любом чате Telegram
2. Нажмите **Переслать**
3. Выберите **@laraue_boards_bot** в качестве получателя
4. Сообщение немедленно появляется в вашем Бэклоге

Это работает для текстовых сообщений, фото, видео, голосовых сообщений, документов и смешанных медиафайлов.

## Что захватывается

При пересылке сообщения Laraue Boards сохраняет:

- **Текстовое содержание** сообщения (до 4096 символов)
- **Фотографии** — хранятся и отображаются как миниатюры на карточке задачи
- **Видео** — хранятся с поддержкой прогрессивной потоковой передачи, воспроизводятся без ожидания полной загрузки
- **Имя отправителя** и **название чата-источника** — отображаются на карточке для контекста
- **Временная метка** — когда было отправлено исходное сообщение

Что не захватывается: реакции, цепочки пересылок, транскрипции голосовых сообщений.

## Медиафайлы в карточках задач

Если задача содержит прикреплённые фото или видео, на карточке появляется горизонтальная полоса миниатюр — видно до четырёх штук, с оверлеем `+N` если их больше. Полоса прокручивается горизонтально.

Нажатие на миниатюру открывает **просмотрщик медиа**: полноэкранный режим с навигацией между всеми вложениями. Видео воспроизводятся с нативными элементами управления.

## Задачи только с медиафайлами

Сообщение не обязано содержать текст, чтобы стать задачей. Фото без подписи становится задачей с только медиафайлами — карточка показывает полосу миниатюр без текста.

## Поддерживаемые типы медиафайлов

| Тип                          | Поддержка                             |
|------------------------------|---------------------------------------|
| Фотографии (JPEG, PNG, WebP) | ✓                                     |
| Видео (MP4, MOV)             | ✓ с прогрессивной потоковой передачей |
| GIF                          | ✓ обрабатывается как видео            |
| Voice messages               | -                                     |
| Documents / files            | -                                     |
| Stickers                     | -                                     |

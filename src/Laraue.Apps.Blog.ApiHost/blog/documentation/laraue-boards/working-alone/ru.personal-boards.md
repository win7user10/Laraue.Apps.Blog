Laraue Boards одинаково хорошо работает и для одного человека, и для команды. Ваша личная организация приватна по умолчанию — без приглашений, без настройки, она уже существует в момент входа.

## Ваша личная организация

При входе вы попадаете на экран выбора организации и можете выбрать **Personal** — свою личную организацию. Всё, что вы создаёте здесь — доски, спейсы, issues, — видно только вам.

![Экран выбора организации со списком Personal, командной организации и кнопкой Create organization](https://laraue.com/static/images/blog/docs/laraue-boards/login-organization.jpg)

Позже вы всегда можете создать командную организацию и перенести туда доски. Личные доски остаются личными, пока вы явно их не перенесёте.

## Типичный соло-флоу

1. **Сообщение приходит в Telegram** — клиент пишет запрос, коллега отмечает баг, вам ставят задачу в групповом чате
2. **Пересылаете боту** — перешлите сообщение боту **@msgboard_bot**. Оно сразу становится issue на вашей доске по умолчанию, без какой-либо настройки
3. **Переносите, когда дойдут руки** — откройте issue, когда будете готовы, и смените его доску или статус, если хотите разместить его не на доске по умолчанию
4. **Работаете с доской** — перетаскивайте карточки по колонкам по мере продвижения
5. **Готово** — карточки в колонке Done не мешаются, но остаются доступными для поиска

## Держите доски небольшими

Частая ошибка — создать одну большую доску на всё. Вместо этого заводите отдельные доски под каждое направление работы:

- Одна доска на клиента
- Одна доска на проект
- Одна доска для личных дел, отдельно от работы

Используйте спейсы, чтобы группировать связанные доски, когда их станет больше четырёх-пяти.

## Работа офлайн

Laraue Boards требует интернет-соединения для синхронизации с Telegram и загрузки досок. Офлайн-режима сейчас нет.

Laraue Boards одинаково хорошо работает как для одного человека, так и для команды. Ваше личное рабочее пространство по умолчанию приватно — организация не нужна, никого приглашать не требуется, ничего настраивать не нужно.

## Ваше личное рабочее пространство

Когда вы входите в систему и выбираете **Личное** на экране выбора рабочего пространства, вы попадаете в своё приватное пространство. Всё, что вы здесь создаёте — доски, пространства, задачи — видно только вам.

Вы всегда можете создать организацию позже и перенести в неё доски. Личные доски остаются личными, если вы не переместите их явно.

## Типичный рабочий процесс для одного пользователя

1. **Сообщения приходят в Telegram** — клиент отправляет запрос, коллега сообщает о баге, вы получаете задачу в групповом чате
2. **Пересылаете боту** — перешлите сообщение @laraue_boards_bot. Оно мгновенно появляется в вашем Бэклоге
3. **Обрабатываете Бэклог** — откройте представление Бэклога и назначьте каждое сообщение на доску и в колонку статуса
4. **Работаете с доской** — перетаскивайте карточки по колонкам по мере продвижения в работе
5. **Готово** — карточки в вашей колонке «Готово» убраны из активного вида, но остаются доступными для поиска

## Использование Бэклога как инбокса

Бэклог — это ваш неназначенный инбокс: всё, что нужно обработать, но ещё не размещено на доске. Думайте об этом как об inbox zero для email: цель — распределить всё по нужным доскам.

Когда Бэклог пуст, в его представлении отображается сводный дашборд всех досок с прогрессом с первого взгляда.

## Поддерживайте доски небольшими

Распространённая ошибка — создать одну большую доску для всего. Вместо этого создавайте отдельные доски для каждой отдельной области работы:

- По одной доске для каждого клиента
- По одной доске для каждого проекта
- Отдельная доска для личных задач, отдельно от рабочих

Используйте пространства для группировки связанных досок, как только их станет больше четырёх-пяти.

## Работа офлайн

Для синхронизации с Telegram и загрузки досок Laraue Boards требует интернет-соединение. Режим офлайн в настоящее время не поддерживается.

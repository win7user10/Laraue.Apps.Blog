Бэклог — место, где задачи живут до назначения на доску. Каждое захваченное сообщение Telegram сначала попадает в Бэклог. Ваша задача — обработать его: решить, на какую доску принадлежит каждая задача и каким должен быть её начальный статус.

## Что показывает Бэклог

Представление Бэклога состоит из двух секций:

**Дашборд обзора досок** — всегда отображается вверху, когда у вас есть доски. Показывает карточку для каждой доски с сегментированным прогресс-баром, количеством задач и разбивкой по статусам. Нажмите на любую карточку доски, чтобы перейти к ней.

**Список неназначенных задач** — ниже дашборда, все задачи, ещё не размещённые на доске. Каждая показывает отправителя, чат-источник, текст сообщения и миниатюры медиафайлов.

## Поиск в Бэклоге

Нажмите иконку поиска в заголовке Бэклога. По мере ввода список фильтруется в режиме реального времени по содержанию сообщения, имени отправителя и названию чата. Количество совпадений отображается под названием заголовка. Нажмите Escape или повторно нажмите иконку для очистки.

## Сортировка обзора досок

Над карточками досок доступны три варианта сортировки:

- **Вручную** — порядок создания досок
- **По названию** — по алфавиту
- **Недавние** — доски с наиболее свежей активностью первыми, удобно при большом количестве досок

**Только активные доски** — включите этот фильтр, чтобы скрыть доски, где все задачи находятся в последней колонке (Готово).

## Назначение задачи из Бэклога

Нажмите на любую карточку задачи, чтобы открыть её детали. Нажмите **Назначить на доску**, чтобы открыть выбор. Выберите доску, затем колонку статуса. Задача немедленно покидает Бэклог и получает ключ доски.

## Настройка названия Бэклога

Нажмите иконку редактирования в заголовке Бэклога, чтобы переименовать его и изменить цвет акцента. Некоторые команды предпочитают называть его «Инбокс», «Обработка» или «Неназначенное». Название косметическое — поведение остаётся тем же.

## Возврат задач в Бэклог

Откройте детали любой задачи с доски и нажмите **↩ Вернуть в Бэклог**. Задача теряет статус и позицию в колонке, но сохраняет ключ.

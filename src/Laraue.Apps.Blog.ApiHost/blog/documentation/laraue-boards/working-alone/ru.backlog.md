Бэклог — это доска, с которой начинается каждый спейс. Каждый issue, который вы сохраняете из Telegram, попадает в Бэклог.

## Что показывает Бэклог

Бэклог — это список issues, которые пока не распределены по статусам. Он отображает их так же, как любая другая доска показывает свои issues, только без колонок. В каждой строке — номер issue, его содержимое и на кого он назначен.

![Бэклог со списком issues](https://laraue.com/static/images/blog/docs/laraue-boards/backlog-view.jpg)

## Поиск в Бэклоге

Нажмите на иконку поиска в шапке Бэклога. По мере ввода список фильтруется в реальном времени. Нажмите Escape или на иконку ещё раз, чтобы очистить.

## Перенос issue с Бэклога

У каждой строки issue справа есть иконка обмена — нажмите её, чтобы назначить issue на другую доску прямо из списка, не открывая полные детали issue.

Также можно открыть сам issue и сменить его доску или спейс там же, как на любой другой доске.
